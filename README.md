# Toralva Trailers Landing

Crea una landing page moderna, sencilla y responsive para “TORALVA Trailers”, un negocio dedicado a:

Fabricación de trailas/remolques.

Venta de refacciones para trailas.

Reparación y mantenimiento de trailas.

Quiero una página de una sola sección larga (one-page), clara y enfocada en captar cotizaciones.

Estilo visual:

Imagen industrial, sólida y profesional.

Color principal: naranja quemado o rojo oscuro.

Letras en amarillo suave/crema, cuidando siempre la legibilidad.

Colores secundarios recomendados: negro, gris carbón y blanco.

Usa fondos alternados para que no se vea demasiado saturada.

Diseño limpio, moderno y apto para móviles.

Incluye imágenes de trailas, talleres, herramientas, refacciones y reparación.

Secciones:

Header con el nombre “TORALVA Trailers” y navegación: Inicio, Servicios, Nosotros, Contacto.

Hero con título: “Trailas fabricadas para trabajar contigo”, texto corto y botones “Solicitar cotización” y “Contactarnos”.

Servicios en tres tarjetas: Fabricación de trailas, Refacciones para trailas, Reparación y mantenimiento.

Beneficios: Calidad, atención personalizada, experiencia y soluciones confiables.

Galería de trabajos/productos.

Contacto con campos editables para teléfono, WhatsApp, correo, ubicación y horario. No inventes información real; usa placeholders como “Agregar teléfono”.

Botón flotante de WhatsApp con enlace editable.

Footer sencillo.

Usa textos en español y un tono confiable, directo y cercano. El resultado debe verse profesional desde el primer vistazo y estar listo para personalizar con fotos reales, datos de contacto y redes sociales.
